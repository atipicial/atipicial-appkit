## 📦 Packages

| Package | Purpose |
|---|---|
| **`@atipicial/appkit-atipicial-adapter`** | The Atipicial Chain adapter — sessions, signing, dAPI |

## ✨ What It Does

- **Universal wallet connections** — pair dApps with Atipicial wallets
- **Session management** — connect, events, disconnect, all typed
- **Method routing** — `invokeFunction`, `send`, `signMessage`, `getBalance`
- **Connect Lab** — a demo playground (`apps/connect-lab`) to test every method

## 🚀 Getting Started

```bash
pnpm install
pnpm dev    # runs the connect-lab playground
```
